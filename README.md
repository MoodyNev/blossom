# This is an terminal audio visualizer inspired by CAVA
Searching for the best audio visualizer for my linux rice I stumbled upon CAVA used it for a long while and played with it configs a lot. If you want to check out CAVA here is the link for it: https://github.com/karlstav/cava. However in time it started feeling too simple and one-dimensional, so I wanted to bring some more movement to my favourite visu It is still in development so if you want to try out always pick the latest blossomX.py version from the list. The reason I keep them in seperate files is to remember progress without having to check past versions or changing the code itself. You can also try out cava8.py which my simple copy of cava itself, before I started coding blossom.
# Required dependencies 
Here is what you might need to install before using it in the terminal:
- numpy==2.5.4
- scipy==1.18.1
- sounddevice==0.5.6
- Also in order for the code to detect device out output, you should replace the constant `DEVICE` with your own device name. I only tested and used it on my own device, so I recommend you to google ways to find your specific device name.

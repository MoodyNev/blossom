# This is an terminal audio visualizer inspired by CAVA
If you want to check out CAVA here is the link for it: https://github.com/karlstav/cava. It is still in development so if you want to try out always pick the latest blossomX.py version from the list. The reason I keep them in seperate files is to remember progress without having to check past versions or changing the code itself. You can also try out cava8.py which my simple copy of cava itself, before I started coding blossom.
# Required dependencies 
Here is what you might need to install before using it in the terminal:
- numpy==2.5.4
- scipy==1.18.1
- sounddevice==0.5.6
Also in order for the code to detect device out output, you should replace the constant `DEVICE` with your own device name. Since it is only my device atm and I haven't tried it out on other machines yet, I recommend googling to find it via the terminal.
